# High-level plan from 2026-11-25

Where we are: every Section V mechanism is implemented and verified, but no prompt component has shown a benefit, offline or in the simulator. The blocker is upstream of everything else: **the policy does not extract information from goal images, even real future frames.** Until that changes, the world model, subtask text, metadata and the final benchmark have nothing to build on.

Deliverable of the project: a written reproduction report that says, with controls, which of π0.7's Section V claims hold at toy scale (SmolVLA ~450M, LIBERO) and which don't, and why. A clean negative result counts.

Each phase has a gate. Don't start the next phase until the gate passes or the phase is written up as a negative result.

## Phase 1: make goal conditioning work (the key pathway)

Question: why doesn't a real future frame help the policy?

1. **Spatial subgoal test** (~25 min GPU). Replace the goal image with the end-of-subtask gripper state (8 numbers) as one extra token. Same A/B recipe from `smolvla_libero_90`.
   - Helps → the information is usable but the frozen vision encoder flattens image goals. Go to 2.
   - Doesn't help → the policy or training budget can't exploit any goal at 2k updates. Go to 3.
2. **Fix the image path** (~1 h each): unfreeze the last vision-encoder blocks for goal tokens, or feed goal-minus-current features. Re-run the A/B with real frames.
3. **Longer training** (~1.5 h): resume the three saved arms to ~10k updates; watch whether the B–A gap opens.
4. **Move to where goals matter**: on fixed-order LIBERO-10 the current image already predicts the next step. Repeat the winning setting on LIBERO-Goal (one scene, 10 instructions), where the goal decides what to do.

**Gate:** B with real goals beats A *and* beats copied-current, with the episode-bootstrap interval excluding zero.

## Phase 2: subtask text (in-between language prompt)

Run subtask text vs full task text on LIBERO-Goal, not LIBERO-10 (Codex's gripper-sign fix is already in). ~25 min GPU.

**Gate:** same as Phase 1, offline, then 20 paired simulator starts.

## Phase 3: plug in the world model

Only after Phase 1 passes.

- Closed loop with ImageWAM goals vs copied-current vs goals off, on the Phase-1 winner.
- Finish the 500-image generated cache and run the generated-images-in-training comparison (the paper mixes generated images into training).
- Test instruction steering on LIBERO-Goal, where ImageWAM already follows text.

**Gate:** generated goals beat copied-current in the simulator on the same starts.

## Phase 4: metadata and CFG (mixed-quality data)

Resume Codex's metadata training pair and the metadata/CFG behaviour sweep.

**Gate:** asking for "quality 5, no mistake" beats asking for low quality on held-out error and on live success, with the mixed-quality data in training.

## Phase 5: final benchmark and report

- Freeze checkpoints and runtime choices; run the reserved LIBERO-10 cohort (100 starts per condition).
- Consolidate: success, progress, paired uncertainty, cost, and a claim-by-claim table of what reproduced.
- Publish the report in the repo.

## Budget

Phases 0–2 are a day of work and under 3 GPU-hours. Phases 3–5 are several GPU-hours each and only make sense if Phase 1 passes. If Phase 1 fails in all four variants, skip to Phase 5 and write it up as the main finding: at this scale and on this data, goal conditioning as described in Section V does not reproduce.
